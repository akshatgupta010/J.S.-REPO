# J.S. Repo

A collection of small JavaScript projects built with HTML, CSS, and JavaScript.

This repository contains beginner-friendly mini projects that demonstrate common front-end interactions and DOM manipulation for conceptual clarity and practice.

## Projects

### Project 1: Color Scheme Switcher
A simple page that lets users click color buttons to change the background color of the page.

- Files: `Project 1/index.html`, `Project 1/style.css`, `Project 1/script.js`

### Project 2: BMI Calculator
A BMI calculator that takes height and weight inputs and displays the calculated result along with the BMI range guide.

- Files: `Project 2/index.html`, `Project 2/style.css`, `Project 2/script.js`

### Project 3: Local Time Display
A page that shows the user's current local time in a styled digital clock.

- Files: `Project 3/index.html`, `Project 3/script.js`

### Project 4: Number Guessing Game
A simple number guessing game where the player tries to guess a random number between 1 and 100 with a limited number of attempts.

- Files: `Project 4/index.html`, `Project 4/style.css`, `Project 4/script.js`

### Project 5: Event KeyCodes
A page that listens for keyboard events and displays the pressed key, key code, and code in a table.

- Files: `Project 5/index.html`, `Project 5/script.js`

### Project 6: Random Background Color Changer
A project with Start and Stop controls that continuously changes the page background to a random color at regular intervals.

- Files: `Project 6/index.html`, `Project 6/script.js`

## How to Run

1. Clone the repository.
2. Open any project folder in a browser.
3. Alternatively, use a live preview extension such as VS Code Live Server for a smoother experience.

Example:

```bash
git clone https://github.com/akshatgupta010/J.S.-REPO.git
cd J.S.-REPO
```

Then open `Project 1/index.html`, `Project 2/index.html`, `Project 3/index.html`, `Project 4/index.html`, `Project 5/index.html`, or `Project 6/index.html` in a browser.
